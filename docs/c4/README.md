# C4 diagrams

Levels: 1 Context, 2 Container, 3 Component. Level 4 (code) is usually skipped.
Keep one file per system, e.g. `01-llm-gateway.md`. GitHub renders Mermaid in Markdown.

Plain flowcharts are the most reliable renderer; the C4 Mermaid syntax is
still experimental, so use it for practice but always check the preview.
